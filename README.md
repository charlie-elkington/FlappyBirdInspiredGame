# FlappyBirdInspiredGame

A Unity 2D project created with C# based on the popular mobile game "Flappy Bird".

## About
This project was created by following a Unity 2D tutorial by "Game Maker's Toolkit" as a starting point. I then implemented my own features to expand upon the project.

## Prerequisites

### To play the game
- No additional software required besides a compatible Operating System

### To open the project
- Unity 6000.4.8f1
- Git (if cloning the repository)

## Features
### From the tutorial:
- Infinitely generating pipes
- Point system
- Jumping and falling
- Dying and respawning

### Features I added:
- Main menu
- Original music
- Sound effects

## My contributions
- I created all the game's artwork and assets using the free online pixel art software "pixilart.com"
- I produced the game music in Logic Pro X
- Added a main menu
- Added sound effects designed in sfxr.me

## Technologies
- Unity
- C#
- Logic Pro X
- sfxr.me for sound effects

## What I learned
This project taught me how top navigate the unity editor, the basics of C#, and how and where to find help if I needed it.
